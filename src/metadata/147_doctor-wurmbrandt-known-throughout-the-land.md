Title: Doctor Wurmbrandt / der im gantzen Land / überall bekandt
Text: Ihr francken Männer und ihr Frauen / Wolt ihr euch einem Arzt  vertrauen / So traut euch mir/ ich bin der recht / Hail bendes Man= und Weibs=geschlecht. / Zeigt nur den Harn/ ich wil bald sehen / Was euch im Leib und Hirn geschehen / Daß ihr euch so Faßnächtisch stellt / Und zu der Narren Zunfft gesellt. / Ich bin ein Meister dieser Sachen / Kan Tumm und Tolle wizig machen: / Erfenn bald an dem Angesicht / Was einem innerlich gebricht / Und muthmaß leichtlich aus Geberden / Was ferner aus euch möchte werden. / Habt ihr vor Würmen keine Ruh / Laufft mir (den Doctor Wurmbrand) zu: / Ich schneid den Wurm/ heil artig wider / Das wurmig hirn und alle Glieder. / Kriegt einer Mauß/ hebt handel an / Die niemand wol erdulten kan // So sang ich sie um wenig bazen: / In meinen ärmel hab ich Kazen / Die senn so voll geschwinder List / Daß keine Ratt auch sicher ist. / Hast du zuviel der Haupts=dachts=sparren / So gibt es Spiz= und doppel=Narren: / Ist dann ein Sparr zu wenig da / So wird der Stocknarr dich gar nah / Zu einem blöden Dölpel machen / Daß Kinder deinr möchten lachen / Ver das Wind und Regen trüngen ein / die ausdermassen schädlich senn. / Verlierst du Zwickel aus der hauben / So fliegen Grillen/ Mucken/ Dauben / Und Schnacken allzeit ein und aus. Da wird dein Kopf ihr eignes haus. / Wann die so hin und wider fliegen / Kanst du wol einen Schiefer kriegen / Als werst du (weiß nicht wie) verlezt / Und fast in Todes Gefahr gesezt. // Schau/ alles das kan ich benemmen / Das Schwindelhirn/ den Schwärmgei / Wann er schon auch von Wein ennzündt / Als wie ein Kolhauss klümt und brinnt: / Und wann du ganz Vierschollig worden / Weist nichts um Ost/ West/ Sud/ und Nordes. / Ja wann dir nimmer wissend ist / Ob du ein Vub oder Mägdlein bist / So trau ich dich zu recht zu bringen / Wann eines nur von üblen Dingen / Nicht überhand gewinnt/ und schafft / Daß mein Urznenen ohne Krafft / Und rechte Würdung ab muß gehen: / Wann nemlich du nicht wilst gestehen / Wilst nicht erkennen/ wer du bist / Und was für Narrheit in die ist / Erzeigst/ dich prächtig aufgeblasen / Als in zwilff weisen Köpffen sen. / O weh/ da must kein Urzenen // Soll dich mein Arzenen erlaben / So must du glauben daran haven / Der Glaub bestättigt alle ding / Ohn ihn ist Kunst und Hülff gering. / Doch komm/ wir wollen es versuchen / In meiner Alchimisten=Kuchen / Da ich den Vrennhelm ausgericht / Komm/ biet den Kopff/ und förcht dich nicht / Wir werden gar in kurzem sehen / Die Dünst in vollem schwang aufgehen / Mit tausendfachen Narren=werck / Daß ich gar wol in dir vermerck / O ho. sie kommen schon gestiegen. / En/ was für Vremen/ was für Fliegen / Was unraths steckt in deinem Kofpp / Du hasen=mässig=wüster Tropff. / Du machst mir warlich mehr zuschaffen / Als fast ein ganzer Wald voll Affen. / Mach ich dich dieser Kranckheit fren / So sag wol/ daß ich Meister sen.
