Title: Le médecin guarissant Phantasie purgeant aussi par drogues la folie;
Caption 1: Aprochez vous qu’avez la teste pleine / de phantasie, qui vous met en grande peine // asseurez vous de ce Maistre sçavant, / quil voz humeurs seicherat tellemant, // dedans ce four, qu’aurez en peu de temps, / grand allegeance de beaucoup de torments, // aussi serez purge per ses brevages / qu’incontinant deviendrez du tout sages.;
Caption 2: Kombt her die ir voll Mucken seit / Und im Kopff groß pein und qual leid / Zie her die ir leidt pein und qual / Im Kopff voll Grillen uberal / Ich euch vor gwiß versichern will / Die selbn vertreiben sanffe und still / Dann ich ein Doctor ganz gescheid / Rumb weak (?) all böse feuchtigkeit / In disen Ofen gar geschwind / Das einer ba’d gut bessrung find / Und ledig werdt viler schmerzen // Die im weh gethan im herzen / Denn der Kopff wird purgirt so rein / Daß es ja nicht kond besser sein / Wie man im Ofen sicht durchauß / Manch selzam deng steigen herauß / Daß einer darob wol möcht lachen / Das es herauß treibt solche sachen / Weil dann zu dieser zeit auch wol / Und ich manchen wol helffen kan / Der komb und sprech mich tröstlich an // Ist er der Grillen toll und voll / Ich im geschwind wil helffen wol / Das er erledigt und gar bald / Er sen gleich jung oder alt / Derhalb bedencst (?) tach wol und ebn / Ein andern rarb (?) kan ich auch gebn / Und euch ein giessen die werßheit / Das von euch weicht die Narheit weit / Als ir den fe..t (?) wie schnell und bhend / Ich Curier hie mein Patient / Also das unten durch vor allen // Dren grosse Narren von im allen / Welche ich treib von im geschwind / Das er darauff sich wol empfind.
An den Leser;
Kein Sscheider nem sich dessen an / An Narren die Kunst probieret man / Dieselben werden so curirt / Kein ander wird damit verirt / Die müssen also schwizen und baden / Als denn so wird geheult ir schaden.
E.K.R.
